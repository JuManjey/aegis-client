Фаза 2 (0.2.0):
• Аккаунты без номера телефона (Argon2id) + восстановление по мнемонике/коду.
• Signal Protocol (X3DH + Double Ratchet) с PSK-в-X3DH.
• Независимый каскад: XChaCha20 → AES-256 → Camellia-256 → Twofish-256.
• Обмен PSK вне сети (QR / мнемоника / NFC).
• Встроенный Tor (Arti): SOCKS5, статус bootstrap, мосты/PT (obfs4/snowflake/meek).
• SQLCipher + StrongBox, биометрический вход, автоблокировка по простою.
• Экстренная очистка (крипто-shredding + best-effort) + пароль-обманка.
• Звонки голос/видео поверх WebRTC/DTLS-SRTP с доп. AEAD-слоем медиа; TURN через Tor.
• Вложения, отчёты о прочтении, «печатает…», чёрный список, «удалить у всех», уведомления.
• Мультидевайс-политика + выборочный зашифрованный перенос аккаунта (QR/файл).
• Темы, RU/EN, обои чата, маскировка иконки.
• Открытый код (GPL-3.0-or-later) + инструменты воспроизводимой сборки; до аудита.
